01 / MAP

사람의 준비에서 사용자 요청까지

Host bootstrap과 지속 배포를 분리한다. Git은 원하는 상태를, AWS는 외부 자원과 Secret 원본을 소유한다.

Runtime request

Client → DNS → IDC :443 → App

Route 53 A record가 고정 Public IPv4를 반환한다. 제공업체 방화벽과 UFW를 지나 Traefik이 환경별 Service로 전달한다.

Telemetry

App → OTel → metrics / logs / traces

Collector가 중앙 입구다. Prometheus 14일, Loki 90일, Tempo 7일 보존 후 Grafana가 조회한다.

DEC / REGISTRYGHCR

ECR 대신 public GHCR

IDC K3s에서 anonymous pull. prod/dev는 SHA tag와 digest로 고정한다.

버린 것: ECR private token 갱신과 imagePullSecret 운영.

DEC / DOMAINfixed

university.neordinary.com

prod, dev, PR preview, Grafana 모두 exact host 계약. 이전 today-sound 식별자는 제거했다.

경계: Route 53은 DNS만 담당하며 사용자 요청을 proxy하지 않는다.

DEC / GITpublic

Infra repository 공개 허용

Argo CD read credential 없이 main을 읽는다. Secret 값은 없고 topology 공개는 수용한다.

남는 책임: public이어도 main write credential과 branch protection은 필수.

DEC / PLATFORMK3s

단일 IDC node

운영 규모에 맞는 최소 단위. app, DB, 관측, control plane이 같은 장애 영역을 공유한다.

재검토: node 장애를 수용할 수 없거나 실제 자원이 부족해질 때.

DEC / IACCFN

Terraform 없음

Kubernetes는 Argo CD, AWS IAM·S3·SES·Route 53 권한만 CloudFormation이 관리한다.

효과: state 파일 없이 AWS 외부 의존성을 반복 생성.

DEC / DOCSsimplified

한 화면 + 필요한 원본만

일회성 Bootstrap checklist와 DR runbook은 제거했다. backup activation 절차는 남긴다.

새 규칙: 이 HTML로 탐색하고 실행할 때만 세부 guide를 연다.

BLOCKER / BE IMAGE

로컬 build는 현재 안전하지 않다.

src/main/resources/.env.local이 실제 bootJar의 BOOT-INF/classes/.env.local에 포함된다.

GitHub Actions clean checkout에는 해당 미추적 파일이 없어 기존 CI image는 안전할 가능성이 높지만, 실제 GHCR artifact를 pull·scan하기 전에는 단정하지 않는다.

GHCR 공개 전: resource 밖으로 이동 → Gradle exclude → .dockerignore 강화 → image JAR 검사 → 로컬 push 이력이 있으면 credential rotation.

waiting

Public IP

waiting

앱 target, Grafana target, ExternalDNS /32 filter를 같은 값으로 변경.

GHCR image

blocked

bootstrap-required tag와 빈 digest. BE pipeline과 image secret scan 선행.

Deployment

off

필수 Secret Ready, DB/runtime 계약, 검증된 tag·digest 뒤 환경별 활성화.

TLS / Ingress

staging

DNS-01 staging 성공 → production Certificate Ready → Deployment health 뒤 Ingress.

Grafana

off

실제 IP, production TLS, anonymous/sign-up 차단, 팀원 Viewer 계정 검증.

DB backup

suspended

수동 dump·checksum·complete marker와 node 밖 restore 성공 뒤 예약 실행.

Root prune

false

첫 운영 안정화와 자식 Application 삭제 복구 절차 확인 뒤 검토.

09 / NEXT

지금 할 일과 나중에 할 일

BE는 지금 건드리지 않는다. 인프라를 먼저 신뢰 가능한 Git root로 만든 뒤 외부 시스템을 연결한다.

Infra repository 생성과 초기 push

UMC-PRODUCT/umc-product-infra public repository를 만들고 remote를 연결한다. CI 성공 후 secret scanning, push protection과 main 보호를 적용한다.

AWS와 OAuth console의 외부 입력 준비

CloudFormation과 Secrets Manager를 준비한다. Google OAuth는 Web Prod, Android Server, Android Release, iOS, 선택적 Android Debug client를 플랫폼 계약에 맞게 등록한다.

IDC server와 고정 Public IPv4 확보

공인 SSH로 Tailscale만 등록하고 이후 관리는 tailnet 경유 OpenSSH로 전환한다. 같은 IPv4를 앱, Grafana, ExternalDNS filter에 반영한다.

BE image 공급 경로 수정

.env.local packaging을 차단하고 실제 image를 scan한다. CI는 public GHCR에 12-char SHA를 게시하고, prod/dev values를 Helm으로 사전 검증한 뒤 digest를 infra main에 직접 기록한다.

dev → prod → preview 순차 활성화

Secret, DB, TLS, DNS와 health evidence를 확인하고 Deployment와 Ingress를 분리해서 연다. Preview lifecycle은 마지막에 연결한다.
